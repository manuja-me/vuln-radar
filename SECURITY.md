| Version | Supported          |

## Reporting a Vulnerability

We take the security of VulnRadar seriously. If you discover a vulnerability, please do **not** disclose it via public GitHub issues, PRs, or discussions.

### Preferred Method: GitHub Private Vulnerability Reporting
Please submit your report through GitHub's [Private Vulnerability Reporting](https://github.com/manuja-me/vuln-radar/security/advisories/new) system:
1. Navigate to the **Security** tab of this repository.
2. Select **Advisories** and click **Report a vulnerability**.
3. Provide details, steps to reproduce, impact assessment, and any proof-of-concept material.

### Response Timeline
- **Acknowledgement**: Within 48 hours of receipt.
- **Triage & Updates**: Regular status updates during investigation and patch development.
- **Coordinated Disclosure**: Once a fix is verified and released, we will coordinate public disclosure and credit you appropriately.
